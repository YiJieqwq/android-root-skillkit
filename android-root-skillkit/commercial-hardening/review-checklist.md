# Root 玩家付费软件安全评审清单

## 适用范围与架构分类

- [ ] 已确认产品从定义开始就面向 Root/玩机用户，而不是普通消费者 App
- [ ] 已确认用户接受严格设备绑定、指纹漂移后官网手动解绑及其可用性成本
- [ ] 已确认 Root 玩家付费用户空间软件 / 付费 KPM / 安全分析工具
- [ ] 未为普通 App 无必要引入 KPM 管理器依赖
- [ ] 未对普通 App 默认要求 KPM 加载；KPM 仅作可选拓展，默认路径零内核依赖
- [ ] 已声明版本商业生命周期和不考虑的高级攻击能力

## 授权与服务器

- [ ] 客户端不能自行伪造服务端签名 Grant
- [ ] Grant 绑定设备实例、版本、清单、nonce 和有效期
- [ ] 有版本 ACTIVE/GRACE/REVOKED 状态
- [ ] 有换绑、吊销、限流和密钥轮换
- [ ] 联网皇冠能力确实位于服务器，而非只做联网布尔校验

## 设备指纹

- [ ] 使用版本化规范化结构，不是无分隔拼接
- [ ] 区分字段不存在、拒绝、错误和真实空值
- [ ] 指纹不直接作为唯一秘密密钥
- [ ] 服务器原则上不保存 IMEI/序列号原文
- [ ] 已覆盖多 SIM、无基带、刷机、换内核和字段漂移
- [ ] 指纹不匹配时 fail-closed，不自动宽松匹配
- [ ] 官网解绑具备身份验证、冷却期、频率限制、审计和旧凭据吊销

## 本地资产

- [ ] 高价值资产不以明文放在 APK
- [ ] 使用成熟 AEAD，nonce 唯一，AAD 绑定上下文
- [ ] 每资产有独立 ID、版本和子密钥
- [ ] 解密失败不存在固定 fallback 或明文降级
- [ ] 真实业务消费解密后的必要资产，不只读取授权布尔值
- [ ] 明文不长期进入 Java String/byte[]、文件或日志

## 拟合

- [ ] UI/点击、Root、worker/IPC、Native、资产形成跨层依赖
- [ ] 检查不是全部汇聚到同一个 `licenseVerified`
- [ ] 跳过流程会缺少真实副作用和状态
- [ ] 拟合点非同构，不能用单一批量 Patch 处理
- [ ] 密码型拟合构成最终边界，UI 只增加定位成本
- [ ] Debug 可诊断，Release 移除敏感状态说明
- [ ] 正版异常可恢复，不依赖恶意崩溃或数据破坏

## 商业加固

- [ ] 壳/VMP 保护的是 Grant、指纹、解密和加载咽喉
- [ ] 未把反 Frida/TracerPid 当作授权根
- [ ] 未宣称运行时绝对不可 Dump
- [ ] 符号文件、崩溃诊断和构建制品有内部保存流程

## KPM（仅适用时）

- [ ] 仅 B 类（产品本身即内核模块）或用户自愿启用时使用 KPM 方案
- [ ] Main 默认 DORMANT
- [ ] Main 独立验签并读取设备/会话上下文
- [ ] Runtime Seed 参与必要的真实运行状态
- [ ] ACTIVE 后才启用核心 Hook
- [ ] Watchdog/Main 心跳失败时安全撤销
- [ ] 不承诺抵抗恶意 KPM、改内核和 EL2
- [ ] 异常不会导致 panic、重启或用户数据损坏

## 反向攻击验收

- [ ] Java/UI 强制成功后功能仍不可用
- [ ] 跳过服务器后拿不到有效资产密钥
- [ ] 旧/伪造 Grant 被拒绝
- [ ] 设备 A 材料不能直接用于设备 B
- [ ] 去壳或不加载 native 后资产消费链断开
- [ ] 只 Patch UI、点击或 Root 任一层不能恢复完整功能
- [ ] 不存在生产导出接口、提取日志或固定密钥
- [ ] KPM 产品中只加载 Dump 的 Main 仍保持 DORMANT
